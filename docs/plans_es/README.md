# Notebook plans (Spanish)

These are the design documents written **before** each notebook was coded (12–14 October 2026). They are in Spanish and they use the old folder names of the first repository (`deep_learning/datos/...`, `deep_learning/resultados/...`). They are kept as a record of the decisions that were fixed before running the experiment.

Equivalences: `datos/processed/experimento` = `data/experiment`, `resultados/figuras` = `results/figures`, `resultados/tablas` = `results/tables`, `comun.py` = `scripts/common.py`.
